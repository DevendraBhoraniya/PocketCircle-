# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in PocketCircle, please do not disclose it publicly via GitHub Issues.

Instead, please send an email describing the issue, reproduction steps, and potential impact to the project maintainers. We appreciate your efforts to responsibly disclose findings and will investigate and respond promptly.
